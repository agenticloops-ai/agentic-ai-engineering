# Release Notes Style Guide

- Lead with the benefit: "Export reports as CSV", not "Added CSV exporter class".
- Use the present tense and the second person: "You can now...".
- Keep each entry to one sentence with no internal names, ticket numbers, or class names.
- For a fix, describe the symptom the reader saw: "Projects with no members no longer crash".
- For a breaking change, add a **Migration:** sentence with the exact action to take.
- Do not use the words "seamless", "robust", or "powerful".
