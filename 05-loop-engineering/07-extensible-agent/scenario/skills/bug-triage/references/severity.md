# Severity Levels

| Severity | Meaning | Example |
|----------|---------|---------|
| critical | Data loss or a security hole | Secrets exposed |
| high | Money or customer promises are wrong | Overselling stock |
| medium | Incorrect output with a workaround | A wrong internal report |
| low | Cosmetic or rare | A confusing error message |

Use `low` for anything classified as `not-a-bug`.
